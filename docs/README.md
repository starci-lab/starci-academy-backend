# docs/ — StarCi backend product docs (Docusaurus mock)

A plain Docusaurus site scaffold. **Mock**: the structure is real and runnable, the content under
`docs/` is placeholder to be filled in section by section.

```bash
cd docs
npm install
npm start          # http://localhost:3040
```

- `docusaurus.config.js` — site config (docs served from `./docs`, sidebar autogenerated).
- `docs/` — the pages (start with `intro.md`).
- `sidebars.js` — autogenerated from the `docs/` tree.

Separate from `.claude/docs/` (the canon site, port 3030), which renders the AI-facing canon in place.

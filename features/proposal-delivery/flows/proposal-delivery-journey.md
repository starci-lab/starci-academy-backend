# Flow · Proposal and document delivery

> ID: `proposal-delivery-journey` · Trigger: A consultation reaches complete project requirements and the buyer requests proposal documents.

| # | Actor | Surface | Action | Result |
|---:|---|---|---|---|
| 1 | `buyer` | `proposal-panel` | Provide or amend required project scope fields | A new requirements revision is recorded |
| 2 | `buyer` | `proposal-panel` | Confirm the current complete revision | The immutable scope snapshot becomes eligible for pricing |
| 3 | `platform` | `proposal-panel` | Price the confirmed scope and generate the document set | Brief, requirements specification and commercial proposal links are returned |
| 4 | `buyer` | `proposal-panel` | Open one generated document link | The immutable project-owned document is streamed |

## Outcomes

- The buyer receives versioned downloadable project documents derived from one confirmed scope

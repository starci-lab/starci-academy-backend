# Flow · Course marketplace and checkout

> ID: `course-marketplace-journey` · Trigger: A visitor opens the course catalog.

| # | Actor | Surface | Action | Result |
|---:|---|---|---|---|
| 1 | `learner` | `course-catalog` | Search, page or change the catalog view | A course set is displayed |
| 2 | `learner` | `course-detail` | Open a course and review its curriculum, prerequisites, reviews, FAQ and offer | The course decision surface is displayed |
| 3 | `learner` | `shopping-cart` | Proceed with the selected cart lines | The backend starts one checkout order for the selected courses |

## Outcomes

- The learner receives a checkout result for the selected course set

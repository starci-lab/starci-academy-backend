# Overview · AgentOS post-install module creation and management

## Purpose

After AgentOS is installed and ready, an end user creates a module by choosing one extensible kind, configures the common module and shared chat plus one kind-specific workbench, validates readiness, and activates the module.

## Included

- Post-install module creation and kind selection
- Common module and shared-chat configuration
- One kind-specific workbench contract
- Readiness validation and activation

## Excluded

- Course learning
- Frontend layout implementation
- Database inheritance strategy
- Concrete workbench integration technology
- Deployment

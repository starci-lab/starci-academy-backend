# Acceptance · AgentOS module management

- A ready AgentOS lets the user choose one registered kind and opens management for the created draft module.
- Management exposes Overview, Shared chat, Workbench and Readiness.
- Different kinds reuse the same shell and chat while resolving different workbench contracts.
- A new kind is selectable without changing the shared shell or chat.
- Missing required settings block activation with specific feedback.
- Changing kind is not offered; the user creates a new module instead.

# Flow · Post-install module setup

| Step | Actor | Action | Result |
|---|---|---|---|
| 1 | AgentOS user | Choose one registered kind | Kind is bound to a new draft |
| 2 | AgentOS user | Configure Overview, Shared chat and Workbench | Settings are saved on the draft |
| 3 | AgentOS user | Check readiness | Ready or actionable missing settings |
| 4 | AgentOS user | Activate module | Module becomes available in AgentOS |

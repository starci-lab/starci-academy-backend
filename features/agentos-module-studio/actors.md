# Actors · AgentOS module studio and adaptive operating shell

## Authenticated owner of one exact ready AgentOS workspace

> ID: `workspace-owner`

### Capabilities

- Browse workspace-owned custom module drafts and published modules
- Start and resume an adaptive module interview
- Answer, correct and extend module requirements
- Attach supporting images and documents
- Configure or remove named integration secrets without reading them back
- Review completeness and explicitly publish or install a ready specification
- Open the one private module setup chat and apply a versioned business context
- Create, rename, resume and archive independent execute chat sessions
- Run and review kind-specific sandbox tests against an explicit module context version before operation

Evidence: `EV-001`

## Authorized collaborator operating one exact module

> ID: `workspace-collaborator`

### Capabilities

- Read the primary Operations feed and allowed additional Execute sessions
- Inspect task evidence and the linked kind Workbench item
- Invoke only actions granted by module permission and kind policy
- Receive proactive reminders, escalations and completion evidence

Evidence: `EV-018`

## Customer or counterpart sending an event through a configured channel

> ID: `external-channel-participant`

### Capabilities

- Send messages and allowed attachments through a verified configured channel
- Receive policy-safe replies and opt out where the kind contract permits
- Never inherit workspace ownership or approval authority from channel identity

Evidence: `EV-018`

## Durable controller assigned to one AgentOS workspace

> ID: `workspace-controller`

### Capabilities

- Authenticate and normalize channel or scheduled events for the exact workspace and module
- Lease and recover durable workspace tasks without losing accepted events
- Apply the installed kind reply contract and bound immutable context version
- Persist proactive message trees, widgets, action evidence and external-delivery results

Evidence: `EV-018`

# States

## Room

`active` → `read-only` → `archived`

## Message

`visible` → `edited` | `author-removed` | `moderator-removed`

## Member chat access

`active` → `muted` | `banned`

## Report

`open` → `under-review` → `dismissed` | `actioned` | `escalated` → `closed`

The latest valid moderation decision is authoritative and auditable.

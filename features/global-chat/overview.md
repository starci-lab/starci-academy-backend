# Global Chat

## Intent

Create one academy-wide, safe, low-friction community conversation space that helps active learners ask, answer, and connect outside a single course context.

## Business value

- Increase learner belonging and return frequency.
- Shorten time to peer help.
- Surface community expertise.
- Create a moderated cross-course community layer.

## MVP boundary

The MVP is one room visible to eligible authenticated academy members. It supports recent history, text, emoji, safe links, replies, reactions, mentions, edit and removal of owned messages, unread state, confidential reporting, and auditable moderation.

Direct messages, member-created rooms, media uploads, voice/video, AI-generated replies, external notifications, and public guest access are out of scope.

# Actors

| Actor | Goal |
| --- | --- |
| Active member | Read and participate in the academy-wide conversation. |
| Moderator | Keep conversation safe, relevant, and recoverable. |
| Community admin | Set policy, appoint moderators, and review escalations. |
| Platform | Enforce eligibility, delivery, unread, and moderation outcomes. |

Guests are not eligible. Muted or banned members are constrained by their current chat-access state.

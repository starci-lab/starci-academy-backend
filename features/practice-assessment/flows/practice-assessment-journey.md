# Flow · Practice and assessment

> ID: `practice-assessment-journey` · Trigger: A learner opens practice or a course assessment route.

| # | Actor | Surface | Action | Result |
|---:|---|---|---|---|
| 1 | `learner` | `practice-hub` | Choose a coding domain, playground or mock interview | The selected setup surface opens |
| 2 | `learner` | `coding-problem` | Submit source code for a problem | A submission and judging job are returned |
| 3 | `learner` | `mock-interview-setup` | Choose course, level and interview kind | The server draws and persists an interview session |

## Outcomes

- The learner receives a judging job or a persisted mock interview session and result path

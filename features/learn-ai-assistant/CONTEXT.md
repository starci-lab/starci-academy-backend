Learn AI Assistant is an individual, course-aware assistant available throughout the Learn workspace. The active course or enrollment owns conversation context and continuity; a lesson, challenge, quiz, current screen, or selected text may refine a request but never owns the conversation.

The approved boundary covers course-level questions, selected-text translation, explanations, summaries, examples, progressive challenge help, context transparency, cross-course isolation, access enforcement, privacy, safety, reliability, cost controls, and measurable learning outcomes.

It explicitly excludes academy-wide community chat, member messaging, automatic assessment submission, canonical grading, instructor communication, and cross-course memory by default. Open policy and provider choices remain launch gates rather than implicit implementation authority.

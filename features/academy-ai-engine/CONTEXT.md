The Academy AI Engine is the shared product contract for AI-assisted capabilities across StarCi Academy. It standardizes authorization, explicit context, learning-integrity policy, model routing, budget, idempotency, typed output, provenance, observability and evaluation while preserving capability-owned journeys and data boundaries.

The modeled capability set is Learn Companion, Challenge Coach, Mock Interviewer, Study Engine, Project Reviewer, Global Chat AI augmentation and operator evaluation. It does not create a universal conversation, cross-course memory, shared grading authority or a single retention boundary.

The approved delivery preference is code-first with a minimum resolver-level E2E proof and representative model-case matrix before release. A broader harness may be deferred, but release evidence, authorization isolation and learning-integrity proof may not be bypassed.

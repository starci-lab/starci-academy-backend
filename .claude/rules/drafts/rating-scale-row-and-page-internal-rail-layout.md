## Luật 4 (STRICT) — Controlled single-select `ListBox` PHẢI dùng `onSelectionChange`, KHÔNG `ListBox.Item onAction` (2026-06-25)
- Bối cảnh: leaderboard category rail + flashcards rail — bấm category/mode/deck **KHÔNG ăn** (thầy: *"bấm challenge không được, bấm đọc bài không được"*).
- **`ListBox selectionMode="single" selectedKeys={[x]}` (CONTROLLED) mà KHÔNG có `onSelectionChange` → React Aria không đổi được selection** (controlled = ngoài quản, không handler để cập nhật) → click chết. `ListBox.Item onAction` **KHÔNG đáng tin** cho "click-để-chọn-drive-state": với `selectionBehavior="toggle"` (mặc định), single-click = SELECT (cần `onSelectionChange`), `onAction` chỉ bắn ở ngữ cảnh action riêng → hay không fire.
- **Pattern đúng:** `onSelectionChange={(keys) => { const key = [...keys][0]; if (key) drive(key) }}` trên CHÍNH `ListBox`; bỏ `onAction` ở item. Đây là canonical controlled-select của React Aria/HeroUI.

# Code-style: i18n (dịch / đa ngôn ngữ)

Phạm vi: cách VIẾT CODE dịch cho FE app — thư viện thật, hook, namespace key, cấm hardcode string user-facing, locale, interpolation. Không bàn design/nội dung bản dịch.

Ground: quét `src` app FE. `useTranslations` xuất hiện ở **474 file**, `react-i18next` **0 file** dùng thật. Idiom = **next-intl**, không phải i18next/react-i18next.

---

## 0. Thư viện thật = `next-intl` (cách grep để chắc)

`package.json` liệt kê cả `i18next`, `react-i18next`, `next-intl` — ĐỪNG tin `package.json`, grep source thật:

```bash
grep -rl "useTranslations" src | wc -l   # 474  -> next-intl
grep -rl "useTranslation\b" src | wc -l  # 0    -> react-i18next chết, KHÔNG dùng
```

**STRICT:** mọi code mới dịch qua `next-intl`. CẤM `import ... from "react-i18next"` / `"i18next"` — dù có trong deps.

## 1. Hook client = `useTranslations` từ `"next-intl"`

✅ ĐÚNG — `src/components/blocks/cards/CourseCard/index.tsx`:
```tsx
import { useLocale, useTranslations } from "next-intl"
const t = useTranslations()
// ...
{t("courses.viewCourse")}
```

❌ SAI — bất kỳ:
```tsx
import { useTranslation } from "react-i18next"   // thư viện chết trong repo này
const { t } = useTranslation()                    // sai cả cách destructure
```

`t` là biến trả về TRỰC TIẾP (`const t = useTranslations()`), KHÔNG destructure `{ t }`.

---

## 2. Namespace: `useTranslations()` rỗng + full dotted key (idiom trội)

Repo dùng 2 cách. Cả 2 hợp lệ nhưng **rỗng + full key là idiom trội (435/474)**:

✅ Trội — không truyền namespace, key là đường dẫn đầy đủ (`CourseCard`):
```tsx
const t = useTranslations()
t("courses.learners", { count })
t("course.continueLearning")
```

✅ Chấp nhận — scope theo namespace khi 1 component bám 1 nhánh key (`src/components/layouts/blog/BlogList/CategoryFilter/index.tsx`):
```tsx
const t = useTranslations("blog")
t("title")                       // = blog.title
t(`categories.${filter}`)        // = blog.categories.<filter>
```

**STRICT:** trong 1 file chọn 1 kiểu, đừng trộn. Key luôn `camelCase.dotted`, phải tồn tại ở **CẢ** `src/messages/en.json` và `src/messages/vi.json` (2 file mirror nhau).

---

## 3. CẤM hardcode string user-facing

Mọi chữ người dùng đọc PHẢI qua `t(...)` + key trong `messages/{en,vi}.json`. CẤM literal tiếng Việt/Anh trong JSX.

✅ ĐÚNG — `CourseCard`:
```tsx
const viewLabel = isEnrolled ? t("course.continueLearning") : t("courses.viewCourse")
```

❌ SAI:
```tsx
const viewLabel = isEnrolled ? "Tiếp tục học" : "Xem khoá"   // hardcode
<Button>Xem khoá</Button>
```

⚠️ Anti-pattern CÓ trong repo nhưng KHÔNG noi theo — ternary locale inline (`src/app/[locale]/contact/page.tsx`, `.../status/page.tsx`):
```tsx
title: locale === "vi" ? "Liên hệ" : "Contact"   // ❌ đừng nhân rộng — đẩy vào messages json
```
Chỉ còn ở ~7 file route/config cũ. Code MỚI: dùng key, không ternary chuỗi.

## 4. Interpolation + plural = ICU trong JSON, không nối chuỗi

✅ ĐÚNG — biến truyền qua object thứ 2 (`CourseCard`):
```tsx
t("courses.learners", { count: course.enrollmentCount })
t("course.priceUsdHint", { amount: formattedPriceUsd })
```
```jsonc
// messages/en.json
"learners": "{count} learners"
// plural dùng cú pháp ICU trong JSON, KHÔNG if/else trong TSX:
"resources": "{count, plural, =0 {No resources} one {# resource} other {# resources}}"
```

❌ SAI:
```tsx
t("courses.learners") + " " + count      // nối chuỗi
count === 1 ? t("one") : t("many")        // logic plural leo vào code
```

Rich text (chèn JSX vào bản dịch) = `t.rich` với chunk callback (`landing.hero.headline`, ...):
```tsx
t.rich("landing.hero.headline", { accent: (chunks) => <span className="text-accent-soft-foreground">{chunks}</span> })
```

## 5. Locale + routing từ `@/i18n/*`, không tự chế

Locale hiện tại: `const locale = useLocale()` (160 chỗ). Cấu hình SSOT ở `src/i18n/routing.ts`: `locales: ["en","vi"]`, `defaultLocale: "vi"`, cookie `LOCALE`.

- Server component / metadata: `getTranslations` từ `"next-intl/server"` (`src/app/[locale]/privacy/page.tsx`):
  ```tsx
  const { locale } = await params
  const t = await getTranslations({ locale })
  ```
- `requestLocale` được đọc trong `src/i18n/request.ts` (`getRequestConfig`) — đừng đọc cookie/param thủ công.
- `useLocale()` chỉ để chọn định dạng/nhánh dữ liệu (`locale === "vi" ? "vi-VN" : "en-US"`), KHÔNG để chọn giữa 2 chuỗi UI (đó là việc của `t`).

**Điều hướng giữ locale-prefix:** dùng wrapper localized ở `src/i18n/navigation.ts` (`Link`, `useRouter`, `usePathname` từ `@/i18n/navigation`). Repo hiện MIX: nhiều nơi còn `next/navigation` / `@heroui/react` `Link`. Khi cần link giữ đúng `/vi|/en`, ưu tiên `@/i18n/navigation`.

# Feature — PersonalProject
> Capstone: xây sản phẩm thật theo milestone→task, nộp GitHub repo, AI chấm theo criteria per-task. Nguồn: `features/learn/PersonalProject`.

- **Job**: 2 surface — dashboard tổng quan (`PersonalProjectDashboard`, khi URL không có `taskId`) và trang 1 task (đọc brief trái / nộp bài phải). Shell: dashboard mirror [[dashboard-hub]] chrome của `CourseContents` (continue-block phẳng, không card viền); trang task = split brief/panel giống Challenge (rail milestone ở `LearnShell.leftRail`, content column tách `flex-1` đọc + `aside xl:sticky top-24` act) → gần với [[master-detail-rail]] + workspace 2-cột lồng trong detail pane.
- **CTA**: dashboard = "Tiếp tục" (`primary lg`, resume tới `currentTask`); mỗi task trong "keep-going path" là 1 `ListRow` bấm được (status icon Play/Check/Lock/Circle quyết định unlock); trang task = hành động nộp/evaluate sống trong `TaskSubmissionPanel` (không tách khỏi doc này, xem panel riêng). → [[call-to-action]]
- **Links (onward)**: `TaskBreadcrumb` là đường lùi trong split view; dashboard's keep-going `ListRow` route thẳng vào `tasks/[id]`; trang kết quả (`/result`) tách riêng khỏi split brief/panel (route match `\/result\/?$/`). → [[content-linking]]
- **Psychology**: `ProgressMeter showValue` + stat line "N/M · attempts · avg score" = đại lượng lớn dần làm headline (mastery framing, đúng [[progress-block-growing-quantity-headline-not-vanity-strip]], không phải stat-strip vanity); chip GitHub "đã kết nối · owner/repo · branch" = social/identity proof của công việc THẬT (không phải badge trang trí); status icon trên mỗi task = "bạn đang ở đâu" liên tục, không cần đếm tay. → [[persuasion-psychology]]
- **Ghi chú**: `PersonalProjectDashboard` là ví dụ CHUẨN cho [[learn-home-surfaces-share-flat-chrome]] (continue-block phẳng, mirror `CourseContents` 1-1) — dùng làm mẫu khi cần dựng thêm 1 "home" khác trong cụm learn.

## Nguyên tắc viết

1. **Biz thuần** — mô tả WHAT, không HOW.
2. **Tiếng Việt** mặc định; tên thực thể giữ nguyên (EN) để map về code.
3. **Không nhúng code, schema, API path, function name.**
4. **Mỗi rule đánh số** để reference (`§02.3` = file 02 mục 3).
5. **Cập nhật khi business thay đổi**, không cập nhật khi tech refactor.

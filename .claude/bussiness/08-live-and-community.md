# 08 — Live & Community

## §08.1 Livestream Session
- **Livestream session** = buổi học tương tác trực tiếp giữa consultant và học viên.
- Có lịch cố định (vd: thứ 7 hàng tuần) hoặc ad-hoc.
- Mỗi session gắn vào course / module / lesson cụ thể (hoặc general).

## §08.2 Quyền tham gia live
- User phải enroll course mà session thuộc về.
- Một số session **open** (preview) — visitor tham gia được, dùng để marketing.
- Capacity giới hạn (vd: 100 slot) — first-come-first-serve.

## §08.3 Sau livestream
- Recording được upload thành **lesson video** đính kèm lesson tương ứng.
- Q&A trong session được consultant chọn lọc, ghim vào QnA lesson (xem §03.6).
- Slide deck của session lưu kèm resource.

## §08.4 Consultant
- **Consultant** = mentor có quyền:
  - Chấm submission (challenge + milestone task + CV).
  - Host livestream.
  - Trả lời QnA.
  - Giới thiệu user vào job partner (xem §07.7).
- Mỗi consultant có profile public: tên, ảnh, mô tả chuyên môn, năm kinh nghiệm.
- Có **consultant-translation** để hỗ trợ bio EN.

## §08.5 Phân công chấm bài
- Một submission có thể được assign consultant cụ thể (manual) hoặc auto-route theo chuyên môn.
- SLA chấm bài: mặc định **48h** kể từ lúc submission `pending`.
- Quá SLA → notify admin để escalate.

## §08.6 QnA workflow
- User hỏi → status `open`.
- Consultant / user khác trả lời → status `answered`.
- User xác nhận đã hiểu → `closed` (optional, không bắt buộc).
- Câu hỏi hay được admin pin lên đầu lesson.

## §08.7 Forum / Community
- v1 không có forum riêng — toàn bộ thảo luận qua QnA lesson + livestream chat.
- Có thể thêm sau (Discord integration hoặc forum module).

## §08.8 Value Proposition entity
- **Value proposition** = câu khẩu hiệu / điểm bán hàng hiển thị landing page.
- Quản lý bởi admin, có thể đa ngôn ngữ (qua translation nếu cần).
- Không liên quan đến học viên trực tiếp — phục vụ marketing.

## §08.9 Quy tắc cộng đồng
- Cấm chia sẻ tài khoản (1 user 1 device đăng nhập cùng lúc).
- Cấm chia sẻ challenge solution công khai trong thời gian course còn active.
- Cấm spam QnA / livestream chat — consultant có quyền mute.
- Vi phạm: cảnh báo → mute tạm thời → khoá enrollment (đơn phương, không refund nếu vi phạm điều khoản).

# Module 16 — Highly Available Distributed Key-Value Store

## Kiến trúc (VI) — 3 bài OSS

| Lesson | Stack | Port API |
|--------|-------|----------|
| **0** | Redis Cluster (Hash Slots + Gossip `CLUSTER NODES`) | **3000** |
| **1** | DynamoDB Local (Master-Replica, ONE / QUORUM) | **3001** |
| **2** | Cassandra 4.1 (Leaderless, Quorum, Read Repair) | **3002** |

**Repo:** `system-design-mastery-module-16-highly-available-distributed-key-value-store`  
**Gossip / failure detection:** chỉ ở **Lesson 0** (Redis Cluster) — không có bài 1 riêng.

Regenerate: `node scratch/apply_module_16_kv_rules.mjs`

---

## Lesson 0 — Redis Cluster

```bash
cd .repo/.../0-redis-cluster-hash-slots-and-gossip/.docker
docker compose up -d --build

curl "http://localhost:3000/api/redis-cluster/map-key?key=item1"
curl http://localhost:3000/api/redis-cluster/gossip-nodes
curl -X POST http://localhost:3000/api/redis-cluster/kill-node \
  -H "Content-Type: application/json" \
  -d '{"node":"0-redis-cluster-hash-slots-and-gossip-redis-2"}'
```

## Lesson 1 — DynamoDB

```bash
cd .repo/.../1-dynamodb-quorum-and-consistency/.docker
docker compose up -d --build

curl -X POST http://localhost:3001/api/dynamodb/write \
  -H "Content-Type: application/json" \
  -d '{"userId":"usr_1","balance":2026,"level":"ONE"}'

curl "http://localhost:3001/api/dynamodb/read?userId=usr_1&level=QUORUM"
```

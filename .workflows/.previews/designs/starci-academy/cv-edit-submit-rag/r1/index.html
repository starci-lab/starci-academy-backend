Design Plan · CV workflow r1

Chỉnh CV, nộp chấm, rồi sửa có căn cứ

Ba hướng dưới đây dùng cùng contract thật: autosave tài liệu block, render PDF, tạo run chấm async, theo dõi trạng thái và đọc score/feedback. RAG là nền tham chiếu rubric/catalog/CV mẫu — không phải một chatbot cạnh CV.

Nguồn: Generated hoặc UploadedRun: Pending → Processing → Done / Failed RAG best-effort, không chặn pipelineScore 0–100 + findings có severity

A · Legacy workbench — parity-first

Giữ nhịp legacy: style rail → block/LaTeX editor → live preview. “Nộp để chấm” là CTA mới nhưng không phá editor quen thuộc.

## Ghi chú (không tính vào số vi phạm — cần thầy xác nhận ý định)

- 10/13 REST controller thiếu `@RestSuccessMessage` (chỉ có ở `keycloak/auth`, `payos/create-payment-link`, `payos/payment-request`) — nhưng đa số là **webhook** (machine-to-machine, không có "success message" cho user) hoặc **admin nội bộ**, nên có thể là ngoại lệ hợp lý chứ không phải lệch. Đáng chú ý: chính `presigned-url.controller.ts` — file mà rubric gọi là "mẫu chuẩn REST" — cũng KHÔNG có `@RestSuccessMessage` dù rule văn bản yêu cầu, cho thấy rule/mold có thể đã trôi so với code thật; nên chốt lại rubric hay code trước khi patch hàng loạt.
- Rule "1 operation = 1 folder", enum thunk `GraphQLType*` wrapper, `@Field`/`@Mutation`/`@Query` bắt buộc `description`, `@GraphQLSuccessMessage` song ngữ trên mutation, validate qua class-validator ở DTO (không validate "chay") — quét mẫu rộng, KHÔNG thấy vi phạm.

## Tổng

**~44 vi phạm cụ thể** (5 reverse-import ở 4 file + 7 resolver-không-mỏng rõ ràng dùng EntityManager/transaction trực tiếp trong mutation + 15 resolver sai tên method + 1 hardcode `@ApiTags` string + 9 controller thiếu `@ApiTags`), cộng thêm diện rộng hơn cần soát kỹ (33 resolver tổng cộng inject EntityManager, phần lớn là query đọc). Mức nghiêm trọng: **reverse-import bussiness→features/api là nghiêm trọng nhất** (phá vỡ chiều phụ thuộc kiến trúc api→bussiness→hạ tầng); còn lại là drift code-style/consistency (naming, resolver dày, Swagger thiếu field).

2 Block vs Primitive

1 block = tập hợp primitives/blocks. Thiếu element → plan phải LIỆT KÊ + đề xuất, không hand-roll ngầm.

block = chức năng

Phục vụ 1 feature, có tên nghiệp vụ.

ContinueCard · CourseCard · DeadlineCallout

primitive = gốc rễ

Generic, không mang feature, tái dùng khắp nơi.

3 Taxonomy variant / scenario / state

variant

Hình thái do PROP lái.

variant="item"|"hero"

scenario = SHAPE

Khác ở COMPOSITION — part NÀO render → anatomy khác. Tách theo SHAPE, không theo tone.

Progress (có bar) vs No-progress

state

Cùng shape, khác data / tone / lifecycle.

không gấp · gấp · loading · error

Nest thêm tầng <scenario> chỉ khi ≥2 shape; 1 shape → state phẳng thẳng dưới variant (vd Item). Title: Block/<cat>/<Component>/<Variant>/<Scenario>, 1 file = 1 scenario.

Ví dụ thật — ContinueCard

ContinueCard ├─ Hero ← variant (prop) │ ├─ No-progress ← scenario · SHAPE không thanh │ │ ├─ Chưa có tiến độ state · loaded │ │ ├─ Đang tải state · skeleton KHÔNG thanh │ │ └─ Lỗi tải state · error │ └─ Progress ← scenario · SHAPE có thanh │ ├─ Không gấp state · chip time NEUTRAL │ ├─ Gấp state · chip time WARNING (urgent) │ ├─ Đang tải state · skeleton CÓ thanh │ └─ Lỗi tải └─ Item ← variant (1 shape → phẳng) ├─ Mục · Đang tải · Lỗi tải

⭐ urgent nằm TRONG shape Progress (là state, khác tone), KHÔNG phải scenario riêng — vì urgent vẫn có thanh, cùng bộ part.

8 Anatomy = ĐÚNG cây DOM thật · per-leaf · group

⭐ Luật vàng (thầy chốt 2026-07-23): anatomy phản ánh ĐÚNG cây DOM/JSX mà leaf đó render — MỌI part render thật đều có mặt (kể cả part cấu trúc như AsyncContent/wrapper), nesting khớp DOM, thứ tự top-to-bottom. Không sót, không dư, không "curate cho gọn". Mỗi leaf tự mang 1 BlockAnatomy RIÊNG — KHÔNG story "Anatomy" gom, KHÔNG blockShell (đã bỏ).

✗ Curate · stub · union
  • Bỏ AsyncContent/wrapper "cho gọn" → THIẾU part
  • Tự viết if(isLoading)… fragment thay AsyncContent port → cây DOM GIẢ
  • Union kể ké: loaded kể Skeleton/Error chỉ state
  • Nesting phẳng dù DOM lồng nhau · Button ×2 rời
✓ DOM-faithful · primitive thật · group
  • Mọi part render THẬT có mặt, children = nesting DOM
  • Dùng primitive THẬT (import port) — cấm stub inline hand-roll
  • Leaf khác composition → *_PARTS RIÊNG; cùng composition → share 1 hằng
  • Cụm ≥2 đồng vai = 1 GROUP (ButtonGroup)

Ví dụ — cây DOM → parts (RelatedContentList, leaf "Nhiều kết quả")

cây DOM THẬT trong code → part (tier) LabeledCard nhãn section frameless · primitive └ AsyncContent switch loading→content · primitive ← CẤU TRÚC, VẪN PHẢI KỂ └ SurfaceListCard khung bordered · primitive └ EntityResultRow ×N mỗi hàng kết quả · design (lặp cùng số)

AsyncContent vô hình về mặt "đẹp" nhưng LÀ một node DOM thật → phải kể. Component phải import AsyncContent port, KHÔNG tự viết fragment — có vậy cây mới trung thực và part mới neo badge được.

Cách bày — panel 2 tab, badge KHÔNG đè nội dung

Tab · Sơ đồ

Render leaf SẠCH + badge số bé ở góc mỗi part (panel ĐO data-anat-part gắn thẳng element, hoặc marker inset-0 do AnatomyOverlay nhả khi showAnatomy). Bảng legend dưới map số → tên · tier · role. Pill/label KHÔNG đè chữ.

Tab · Cây

Bỏ render, chỉ vẽ quan hệ lồng nhau (cái gì chứa cái gì) — thứ overlay phẳng không diễn tả được. Số khớp tab Sơ đồ.

Tương tác: bấm badge (hoặc hàng legend) → tụ sáng: part đó + tổ tiên giữ sáng, phần còn lại mờ đi; bấm lại để bỏ chọn. name trong spec phải KHỚP tag/label part thật thì badge mới neo đúng. Tier: block design primitive.

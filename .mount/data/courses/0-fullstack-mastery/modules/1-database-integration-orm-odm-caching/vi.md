# title
Tích hợp Cơ sở dữ liệu với ORM, ODM và Caching

# description
Tích hợp PostgreSQL (TypeORM) và MongoDB (Mongoose), thiết kế schema và quan hệ dữ liệu, đồng thời áp dụng Redis caching. Hiểu khi nào nên dùng SQL hoặc NoSQL trong hệ thống thực tế.
